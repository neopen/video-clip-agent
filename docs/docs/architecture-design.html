文档定位：这是一篇架构文档。重点是解释组件之间的职责、数据流和关键设计取舍，并区分当前实现与设计层面的推演。
事实边界：实现文档：功能、接口和代码行为以文中标注版本对应的源码为准；仓库后续版本可能发生变化。
权威来源：PenClip 源码仓库；涉及版本历史时，以仓库 Release / CHANGELOG 为准。
代码标记：如果正文出现“源码/实现”字样，表示对应代码路径可在仓库中核对；示例代码仅用于演示调用方式，不应理解为项目源码原样。

读完本文后，你应该知道什么

  • 哪些内容属于当前版本的实现，哪些内容需要以仓库最新代码重新核对。

  • 遇到行为与本文不一致时，应该优先检查版本、配置和源码，而不是继续沿用旧结论。

基于前期的架构规划，现给出完整的项目结构及顶层架构设计。重点考虑扩展性、可维护性和设计模式的合理运用。

设计原则

原则 说明 体现
开闭原则 对扩展开放，对修改关闭 能力注册机制、插件化架构
依赖倒置 依赖抽象而非具体实现 智能体基类、工具接口抽象
单一职责 每个模块只负责一件事 智能体拆分、中枢职责分离
接口隔离 小而专的接口优于大而全 Agent 接口、工具接口分离
迪米特法则 减少模块间耦合 通过中枢协调，智能体不直接通信
策略模式 算法可互换 匹配策略、LLM 提供商切换
观察者模式 状态变更通知 状态管理器推送到前端
工厂模式 对象创建封装 智能体工厂、能力工厂

设计模式应用

设计模式 应用位置 解决的问题
工厂模式 AgentFactory, LLMFactory, GraphFactory 统一创建复杂对象，便于扩展新类型
策略模式 LLMService 各实现类 算法可互换（切换 LLM 提供商）
观察者模式 EventBus, 状态变更推送 解耦状态变更与响应逻辑
责任链模式 中间件链（认证→限流→日志） 灵活组合请求处理逻辑
适配器模式 *Repository 实现类 适配不同存储后端
单例模式 CentralHub, EventBus 确保全局唯一实例
模板方法 BaseAgent.execute() 定义执行骨架，子类实现细节
命令模式 Operation 历史记录 支持撤销/重做
建造者模式 TimelineBuilder, SlotBuilder 构建复杂的时间线对象
代理模式 PluginAgent 为插件提供访问控制
装饰器模式 CacheableLLMService 为服务添加缓存能力
依赖注入 API 层 dependencies.py 解耦依赖创建与使用

并行处理设计

import asyncio
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor

class ParallelProcessor:
    """并行处理引擎"""
    
    def __init__(self, config: Dict):
        self._thread_pool = ThreadPoolExecutor(max_workers=config.get("thread_workers", 10))
        self._process_pool = ProcessPoolExecutor(max_workers=config.get("process_workers", 4))
    
    async def parallel_analyze(self, assets: List[VideoAsset]) -> Dict[str, AnalysisResult]:
        """并行分析多个视频"""
        tasks = []
        for asset in assets:
            # 每个视频分析任务独立执行
            task = asyncio.create_task(self._analyze_single(asset))
            tasks.append(task)
        
        # 并发执行所有分析任务
        results = await asyncio.gather(*tasks, return_exceptions=True)
        return self._collect_results(assets, results)
    
    async def batch_match(self, slots: List[Slot], candidates: List[Segment]) -> List[MatchResult]:
        """批量匹配（每个槽位独立匹配）"""
        semaphore = asyncio.Semaphore(self._config.get("max_concurrent_matches", 5))
        
        async def match_with_limit(slot: Slot):
            async with semaphore:
                return await self._match_single(slot, candidates)
        
        tasks = [match_with_limit(slot) for slot in slots]
        return await asyncio.gather(*tasks)

资源隔离与配额

class ResourceManager:
    """资源管理与隔离"""
    
    def __init__(self, config: Dict):
        self._user_quotas: Dict[str, UserQuota] = {}
        self._global_limits = config.get("global_limits", {})
    
    async def acquire(self, user_id: str, resource: ResourceType, amount: int) -> bool:
        """申请资源，检查配额"""
        quota = self._user_quotas.get(user_id)
        if not quota:
            return False
        
        # 检查用户配额
        if not quota.has_remaining(resource, amount):
            return False
        
        # 检查全局限制
        if not self._check_global_limit(resource, amount):
            return False
        
        quota.consume(resource, amount)
        return True
    
    def release(self, user_id: str, resource: ResourceType, amount: int):
        """释放资源"""
        quota = self._user_quotas.get(user_id)
        if quota:
            quota.release(resource, amount)
